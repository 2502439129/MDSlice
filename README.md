> [!INFO] **本文件用应用自身的语法写成**
> 把本文件拖进应用，或把它和三个文件放在同一目录后用首页打开，即可直接看到目录、元数据卡、提示框、表格与层级缩进的真实效果。

## 〇、它解决什么问题

较长的项目文档（操作手册、设计说明、变更记录）翻阅时，总是要来回滚动翻阅，费时费力。在文档流中各章节的区分也不明显，很枯燥。
为了看文档而反复切换工具也很不方便，因此做了这个纯本地 MD拆分阅读工具。

MDSlice 把文档按标题**切成章节块**，一次只显示一章：

| 能力 | 说明 |
|---|---|
| 章节化阅读 | 按 `H1 / H2 / H3` 切页，点目录即切换，位置不丢 |
| 多标签页 | 同时打开多份文档，各自独立的目录、滚动位置与展开状态；支持拖拽排序 |
| 首页 | 常驻第一个标签页（不可关闭）：用静态服务器打开时自动列出同目录的 markdown，也可「添加目录」或把文件夹拖进来；点列表里的文件即开新标签页 |
| 自动目录 | 左侧三级目录树（可折叠、可拖宽、可一键全折/全展），右侧列出当前 `###` 页的 `H4 / H5` 小节并滚动高亮 |
| 内容增强 | 标题级元数据卡、`[[xx]]` 徽章、`└` 可折叠表格、`:::tabs` 标签页、`:::details` 折叠块、四种 Callout 提示框 |
| 零构建零后端 | 一个入口 `MDSlice.html` + `css/`、`js/` 下的模块文件，除代码高亮外无外部依赖 |

> [!TIP] **和通用 Markdown 预览的区别**
> 通用预览器是「整篇渲染 + 滚动」；本应用是「按章节切块 + 显隐」。因此它对标题层级有要求，具体规则见 [`MD结构说明.md`](MD结构说明.md)。

## 一、快速开始

| 方式 | 操作 | 说明 |
|---|---|---|
| 选择文件 | 顶栏「打开 MD」 | 任意位置的 `.md`，不限制文件名 |
| 拖拽 | 把 `.md` 拖到页面任意位置 | 最快，拖入即渲染 |
| 自动列出 | 用本地服务器打开（如 `python3 -m http.server 8000`），入口文件名不能是 `index.html`（本仓库用 `MDSlice.html`） | 首页自动列出同目录的 markdown（不含 markdown 的空目录不显示），点一下即读 |
| 添加目录 | 首页「添加目录」选择文件夹，或把文件夹拖进页面 | 只列出其中的子文件夹与 markdown；其他文件、构建 / 缓存目录、以及**不含 markdown 的空目录**都不显示 |

可接受的后缀：`.md` / `.markdown` / `.txt`。

**每次打开都是一张新标签页**；若同名文件已经开着，会直接替换掉那一页并重新读取文件。

> [!WARNING] **双击 `MDSlice.html` 直接打开时的限制**
> `file://` 协议下浏览器会拦截本地文件读取，所以**首页无法自动列出同目录**（会显示一段说明）。此时「打开 MD」、拖拽与首页的「添加目录」**依然可用**。
> 想让首页自动列出同目录，请通过本地服务器打开：
> ```bash
> python3 -m http.server 8000
> # 浏览器访问 http://localhost:8000
> ```

> [!WARNING] **起了本地服务器仍然列不出目录：同目录有 `index.html` 时**
> 静态服务器会把「目录请求」优先交给该目录的 `index.html`，返回的是页面本身、不是目录列表，首页的目录卡会显示一条说明——这是服务端行为，浏览器端无法绕过。本仓库的入口已命名为 `MDSlice.html`，同目录因此能正常自动列出；**一旦把入口改回 `index.html` 就会复现**。此时任选其一：
> 1. 让该目录里没有 `index.html`（入口文件名别叫 `index.html`，本仓库用的是 `MDSlice.html`）；
> 2. 用强制目录索引的服务器：nginx `autoindex on;`、Apache `DirectoryIndex disabled` + `Options +Indexes`；
> 3. 直接用首页「添加目录」选本地文件夹（不依赖服务器）。

## 二、界面导览

| 区域 | 内容 |
|---|---|
| 顶栏 | **`⌂ 首页`**（常驻第一个标签页，不可关闭、不可拖动）、`☰ 目录`（窄屏且当前是文档时显示，开合左侧目录抽屉）、**标签条**（当前打开的文件，`×` 关闭）、`打开 MD`、`◐ 暗色 / ◐ 亮色` |
| 首页内容 | 「已打开的文件」列出当前所有标签页，可切换、可关闭；「目录」列出每个目录下的子文件夹与 markdown，点文件即开新标签页，`刷新` / `移除` 管理目录。`file://` 打开时无法自动列目录，此处显示说明与「添加目录」入口 |
| 左侧目录 | 由标题自动生成的三级目录；行首箭头折叠子级；顶部右侧「全部折叠 / 全部展开」；与正文之间有拖动条 |
| 正文 | 当前章节内容；标题下内容按层级缩进，悬停该区域显示引导线；标题前带 `H1`…`H6` 级别标记 |
| 右侧「本章目录」 | 仅 `###` 页生成，列出该页 `H4 / H5` 小节并随滚动高亮；该页没有小节时整栏自动隐藏 |

浏览器标签页标题取自文档**首个章节的元数据 `title`**，没有元数据时取该标题文本；没有打开任何文档时为 `MDSlice`。

## 三、常用操作

#### 标签页

| 操作 | 效果 |
|---|---|
| 点标签条上的文件名 | 切换到该文档；它的目录折叠状态、滚动位置、展开的小节都原样恢复 |
| 点首页列表里的文件名 | 打开该文件；**同一顶层目录下的同一路径**已打开则直接切过去（不重读），行尾带「已打开」角标。标签条只显示文件名（不显示路径，重名也不加前缀），同名文件靠**悬停标签看完整路径**或首页列表区分 |
| 首页「添加目录」/ 拖入文件夹 | 把本地文件夹加进首页；只收子文件夹与 markdown，忽略其他文件及 `.git`、`node_modules` 等目录 |
| 目录行「刷新」/「移除」 | 重新读取该目录 / 从首页列表里移除（不影响已打开的标签页） |
| 首页目录树 | 点目录名展开 / 折叠（子目录按需读取，读取时箭头转圈）；`过滤文件或目录…` 只留命中项并高亮、自动展开其所在层级；`展开全部` / `折叠全部`；键盘 `↑` `↓` 移动、`←` `→` 折叠 / 展开、`Enter` 打开 |
| 点标签上的 `×` | 关闭该页；若关的是当前页，会激活右侧邻居（没有则左侧） |
| 点「打开 MD」（或拖入文件） | 新开一页 |
| 拖拽标签 | 调整顺序（拖动时左右出现落点提示线） |
| 打开同名文件 | 关闭原标签页并**在原位置**重新读取、打开 |
| 关掉最后一页 | 回到空状态提示 |

标签页不会持久化——刷新后需要重新打开文件；主题与侧栏宽度仍然记住。

#### 折叠与展开

| 位置 | 操作 |
|---|---|
| 目录行首箭头 | 折叠 / 展开该章节的子级（只折叠，不影响跳转） |
| 目录行文字 | 切换到该章节；若是子章节，祖先会自动展开 |
| 「全部折叠 / 全部展开」 | 一次性处理整棵目录树 |
| 章节内子章节 | 点 `H1` / `H2` 页时，该章下所有子章节会依次展开显示 |
| 折叠表格 | 表头右侧「全部折叠 / 全部展开」；父行左侧按钮可单独折叠，按钮旁显示子项数量 |

#### 拖拽与主题

| 操作 | 效果 |
|---|---|
| 拖动侧栏与正文之间的竖直条 | 调整目录宽度（宽度会记住） |
| 点 `◐ 暗色 / ◐ 亮色` | 切换主题；首次进入跟随系统 `prefers-color-scheme`，之后记住手动选择 |
| 右侧目录点击 | 跳到该小节；若小节在别的章节，会先切章再定位 |

#### 代码与表格

| 元素 | 交互 |
|---|---|
| 代码块 | 标题栏显示语言与 `title`（如 `title="src/app.js"`），右上角「复制」按钮一键复制 |
| 表格 | 窄屏（≤820px）自动卡片化，每格显示列名；长表格可横向滚动 |
| 提示框 | `[!INFO]` / `[!WARNING]` / `[!DANGER]` / `[!TIP]` 四种颜色与图标 |
| 标签页 | `:::tabs` 内点标签切换；`:::details` 点标题展开 |

#### 锚点跳转

文档里的 `[文字](#锚点)` 会被接管为**章节内跳转**，不会刷新页面：

1. 先按原样匹配章节 id，再依次回退到「slug 化」「去短横线」「唯一前缀」匹配
2. 锚点指向当前页内的小节（如 `#使用步骤`）时，交给浏览器平滑滚动
3. 锚点指向**别的章节**时，先切到那一章再定位

标题右侧的 `#` 号是自身的锚点链接，鼠标移上去才显示。

## 四、文件结构

```text
MDSlice/
├── MDSlice.html        # 唯一入口：结构、图标精灵、按顺序加载 css/ 与 js/
├── css/                # 样式按职责拆分（加载顺序即优先级）
│   ├── 01-tokens.css   # 设计令牌（深浅色）与基础排版
│   ├── 02-layout.css   # 顶栏、标签条、网格骨架、侧栏、右栏与响应式
│   ├── 03-markdown.css # 文档内容：标题、元数据卡、Callout、徽章、表格、代码块
│   └── 04-home.css     # 首页与文件树
├── js/                 # 逻辑按职责拆分（经典脚本，共享全局作用域，顺序即依赖）
│   ├── 01-core.js      # DOM 引用、全局状态、通用工具
│   ├── 02-markdown.js  # Markdown 解析与渲染
│   ├── 03-render.js    # 章节切分、目录树、左/右栏、章节切换
│   ├── 04-tabs.js      # 标签页模型与标签条
│   ├── 05-shell.js     # 主题、顶栏、侧栏宽度、打开文件
│   ├── 06-dirs.js      # 目录来源与文件树数据
│   ├── 07-home.js      # 首页界面与文件树交互
│   └── 08-boot.js      # 启动流程
├── README.md           # 本文件：使用说明
├── MD结构说明.md       # 渲染机制：切页 / 锚点 / 表格 / 容器的实现规则
└── doc.md              # 应用自带的示例文档（不再自动加载，从首页列表点开）
```

## 五、部署与离线

| 场景 | 做法 |
|---|---|
| 静态托管 | 把三个文件（可再放若干 md 作内容）放到任意静态空间 / 对象存储 / GitHub Pages 即可，无服务端逻辑 |
| 内网 / 离线 | 把 `MDSlice.html` 里三个 CDN 链接（highlight.js 与两套主题 CSS）换成本地文件；其余功能不依赖网络 |
| 作为文档入口 | 把要展示的 md 与三个文件放同一目录，用本地服务器打开，首页会列出它们 |

> [!INFO] **外部依赖只有代码高亮**
> 解析器、目录、表格折叠、容器全部自己实现（见 `js/02-markdown.js` 与 `js/03-render.js`），不依赖 marked 等库。CDN 不可用时代码块不会高亮，其余功能正常。

## 六、已知限制

| 限制 | 说明 |
|---|---|
| 无全文搜索 | 章节切换靠目录；跨章查找请用浏览器自身的 `Ctrl/⌘ + F`（仅当前章节内有效） |
| 不支持删除线 `~~text~~` | 会按字面显示，请不要使用 |
| 只放行 `<br>` | 其他 HTML 标签会被转义成文字；`<br>` 建议只用在表格单元格里 |
| 代码围栏不能嵌套 | 外层代码块内不能再出现单独的三个反引号行 |
| 一页一章 | `H1 / H2 / H3` 会切页，`H4` 及以下留在页内；章节内部不要再用 `H3` |
| 元数据只支持单行标量 | 不支持数组 / 对象 / 多行值 |
| 标签页不持久化 | 刷新后标签页清空；正文可能很大，不适合放进 `localStorage` |

浏览器要求：Chrome / Edge / Safari / Firefox 近几版均可（用到 `fetch`、`IntersectionObserver`、CSS Grid、`position: sticky`、`backdrop-filter`）。

## 七、再往下看

写文档时若不确定「某个写法会渲染成什么样」，看 [`MD结构说明.md`](MD结构说明.md)：里面写了切页规则、元数据识别条件、锚点匹配顺序、表格列语义、缩进模型与支持/不支持的完整清单。

> [!TIP] **想让文档被正确切页**
> 只要保证 `H1`（全文唯一）→ `H2`（章）→ `H3`（节）的层级语义，`H4` 及以下当作页内小节使用即可，其余交给渲染器。
